# Sistema de Academia - Projeto Evolutivo Individual

## 📌 Sobre o Projeto
Este projeto consiste num sistema de gestão para uma academia, desenvolvido em PHP com a aplicação de princípios de Programação Orientada a Objetos (POO). O objetivo principal é estruturar e organizar o controlo de alunos, professores, planos, matrículas, exercícios e pagamentos de forma modular e eficiente.

---

## 🎯 Problema que Resolve
O sistema simula o cenário operacional de uma academia, automatizando o registo e a organização das informações essenciais para o funcionamento do estabelecimento, evitando inconsistências de dados e facilitando a gestão diária.

---

## ⚙️ Como foi Desenvolvido
O projeto foi construído de raiz utilizando uma arquitetura orientada a objetos em PHP, estruturada por classes independentes que representam entidades do mundo real. A execução e os testes locais foram configurados através de um ambiente de desenvolvimento local (XAMPP).

---

## 🚀 Principais Funcionalidades
* Registo e gestão de Alunos e Professores.
* Atribuição e controlo de Planos de treino.
* Criação de Matrículas associadas a alunos e planos.
* Gestão de Exercícios físicos e Pagamentos.

---

## 🛠️ Tecnologias Utilizadas
* **PHP** (Linguagem principal baseada em OOP)
* **HTML/CSS** (Para a estruturação básica de visualização)
* **Git e GitHub** (Controlo de versões)
* **XAMPP / Apache** (Servidor local)

---

## 🧩 Conceitos de POO Aplicados
O código implementa os seguintes pilares e conceitos fundamentais da Programação Orientada a Objetos:
* **Classes e Objetos**: Estruturação de entidades como `Aluno`, `Professor`, `Plano` e `Matricula`.
* **Encapsulamento**: Proteção e manipulação controlada dos atributos das classes através de métodos de acesso.
* **Associação entre Objetos**: Relacionamento direto entre classes (por exemplo, uma `Matricula` que associa um `Aluno` a um `Plano`).
